# 📱 Tech Phones

A **Tech Phones** é uma loja virtual de smartphones novos e usados, desenvolvida com foco em praticidade, organização e facilidade de navegação.

## 🚀 Funcionalidades

- Catálogo de smartphones.
- Pesquisa de produtos.
- Filtros por marca e condição.
- Seção de categorias.
- Solicitação de avaliação para troca de aparelhos (Trade-in).
- Atendimento e contato pelo WhatsApp.
- Layout responsivo para diferentes dispositivos.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 📂 Estrutura do projeto

```text
Tech-Phones/
├── index.html
├── style.css
├── script.js
└── README.md
```

## ▶️ Como executar

1. Clone o repositório:

```bash
git clone https://github.com/Beatriz-Preiraa/Tech-Phones.git
```

2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` no navegador.
